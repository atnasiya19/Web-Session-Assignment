# Web Session Assignment

A Computer Networks group project demonstrating how web sessions work through cookies, session expiration, and logout behavior.

## About the Project

This project uses a Flask web application to demonstrate how websites manage user sessions and authentication.

It provides a practical demonstration of:

- **Cookies:** Understanding how browsers store and manage cookie information.
- **Session Management:** Understanding how sessions maintain user authentication across requests.
- **Session Expiration:** Demonstrating what happens when a user's session expires.
- **Logout Functionality:** Demonstrating how users log out and how their sessions are terminated.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/fgmaii/Web-Session-Assignment.git
```

### 2. Navigate to the project directory

```bash
cd Web-Session-Assignment
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

For Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Open the local address displayed in the terminal in your web browser.
